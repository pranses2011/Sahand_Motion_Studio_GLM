## 🚀 شروع سریع

1. فایل `logo-motion-studio-pro.html` را در مرورگر **Chrome** یا **Edge** باز کنید
2. روی **✨ قالب‌ها** کلیک کنید و یک قالب آماده انتخاب کنید (۲۵ قالب)
3. لوگو و اطلاعات برند خود را وارد کنید
4. انیمیشن‌ها و افکت‌ها را تنظیم کنید
5. روی **▶** کلیک کنید تا پخش شود
6. روی **⬇️ خروجی** کلیک کنید و فرمت دلخواه را انتخاب کنید

## ⌨️ میان‌برهای کیبورد

| میان‌بر | عملکرد |
|--------|--------|
| `Space` | پخش / توقف |
| `←` `→` `↑` `↓` | جابجایی ظریف عنصر انتخابی |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Redo |
| `Ctrl+D` | کپی عنصر |
| `Ctrl+S` | ذخیره پروژه |
| `Ctrl+G` | گروه کردن عناصر |
| `Ctrl+U` | حذف گروه |
| `Ctrl+A` | انتخاب همه عناصر |
| `Delete` | حذف عنصر انتخاب شده |

## 📋 جریان کار پیشنهادی

1. قالب آماده انتخاب کنید (یا از صفر شروع کنید)
2. لوگو و اطلاعات برند را وارد کنید
3. انیمیشن ورود/خروج هر عنصر را تنظیم کنید
4. پس‌زمینه و افکت‌های Post-FX را انتخاب کنید

8. خروجی بگیرید
