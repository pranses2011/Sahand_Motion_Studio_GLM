## 💡 نکات مهم

1. **اولین بارگذاری:** اپلیکیشن به اینترنت نیاز دارد تا فونت‌ها و کتابخانه JSZip را بارگذاری کند. پس از آن کاملاً آفلاین کار می‌کند.
2. **خروجی WebM به MP4:** از HandBrake یا ffmpeg استفاده کنید: `ffmpeg -i input.webm -c:v libx264 output.mp4`
3. **ذخیره پروژه:** همیشه قبل از بستن مرورگر، از 💾 ذخیره فایل JSON را دانلود کنید.
4. **موبایل:** اپلیکیشن برای دسکتاپ بهینه شده است. روی تبلت با صفحه بزرگ قابل استفاده است.
